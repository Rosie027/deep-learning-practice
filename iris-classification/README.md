# 鸢尾花分类：KNN、SVM 与决策树

使用 scikit-learn 内置 Iris 数据集比较 KNN、SVM 和决策树三类传统机器学习分类器。原文件夹名称包含“CNN”，但该实验没有使用卷积神经网络，因此公开版采用准确的项目名称。

## Notebook

- `notebooks/knn.ipynb`：标准化、K 值搜索、分类报告和混淆矩阵；
- `notebooks/svm.ipynb`：线性/非线性核、参数搜索与决策边界；
- `notebooks/decision-tree.ipynb`：树模型训练、参数选择、特征重要性与树结构可视化。

## 处理流程

```text
load_iris → 训练/测试划分 → 特征标准化（KNN/SVM）
          → 模型训练与参数搜索 → 准确率/分类报告/混淆矩阵
```

历史实验中 KNN 和决策树的部分划分达到 100%，SVM 约为 91%～98%。Iris 数据量较小，这些结果不应理解为模型在未知真实数据上的稳定性能。

`results/` 保存整理前导出的可视化图片；公开 Notebook 已清除本机警告日志和执行输出。
